# Security reporting

This repository has no configured security contact address or disclosure SLA. If you find a suspected vulnerability, do not publish recordings, credentials, or other private artifacts in a public issue. Contact the repository owner through an agreed private channel and include a minimal description, affected revision, and safe reproduction details. The owner should add a durable private reporting channel before inviting external security reports.

The current deployment assumptions and source-backed controls are in [the security model](docs/SECURITY-MODEL.md). This policy does not authorize a whole-repository scan, external testing, or publication of findings.
